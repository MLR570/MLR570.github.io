On correctness

Every worked example reproduced on this site has been recomputed independently and checked against the original.

The interactive figures compute their results numerically at run time rather than showing a saved answer, so what you see is what the math actually does, including at the awkward edge cases.

How it is built

Plain HTML, CSS and JavaScript, with no framework and no build step. Math is typeset with KaTeX. Every interactive figure is a small self-contained module drawing to a <canvas>, sharing one plotting and interaction library. The numerical routines behind them (SVD, eigendecomposition, row reduction) are implemented from scratch so the pages stay dependency-free.

The site is static and hosted on GitHub Pages, which means it loads fast, works offline once cached, and will keep working long after any particular JavaScript framework has gone out of fashion.

Found a mistake?

Please report it. A typo in an exponent can cost a student an hour, and there is no reason for anyone else to lose that hour too. Email varam@mit.edu or b00081313@aus.edu, or raise it in class.

That includes the interactive figures: if a playground behaves oddly, gives a result you cannot reproduce by hand, or is confusing rather than clarifying, that is a bug worth hearing about.
